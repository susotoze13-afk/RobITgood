# Дизайн: Агент-верификатор гипотез

**Дата:** 2026-04-24
**Проект:** AI-RobITGood — агентная система
**Приоритет:** Второй агент к реализации (после research-agent)

---

## Обзор

Агент-верификатор гипотез принимает отчёт ресёрч-агента, генерирует 3-5 гипотез решений проблемы аудитории, показывает их пользователю, задаёт 3 уточняющих вопроса по критериям оценки, скорит гипотезы по матрице, верифицирует финалиста через целевой поиск и сохраняет результат в Google Docs.

---

## Секция 1: Поток работы

```
Вход: ссылка на Google Doc ресёрч-агента  ИЛИ  текст отчёта в контексте
    ↓
[Если ссылка] → firecrawl_scrape читает полный текст документа
    ↓
Агент анализирует отчёт и генерирует 3-5 гипотез решений
    ↓
Показывает все гипотезы пользователю одним сообщением
    ↓
Задаёт 3 уточняющих вопроса по одному:
  — Скорость реализации vs масштаб решения (1-5)
  — Бюджет: минимальный / умеренный / не ограничен
  — Простота для аудитории vs полнота функциональности (1-5)
    ↓
Скорит все гипотезы по матрице критериев
    ↓
По финалисту запускает 1-2 целевых brave_web_search запроса
  (примеры реализации, провалы похожих решений, рыночные данные)
    ↓
Выбирает победителя с обоснованием
    ↓
Создаёт Google Doc → возвращает ссылку + 2-3 предложения резюме
```

---

## Секция 2: Уточняющие вопросы (диалог с пользователем)

Агент задаёт вопросы строго по одному, ожидая ответа после каждого:

**Вопрос 1:** "Насколько важна скорость реализации по сравнению с масштабом решения? Оцените от 1 (важнее масштаб) до 5 (важнее скорость)."

**Вопрос 2:** "Каков бюджет на разработку?
- Минимальный — только open-source, без платных сервисов
- Умеренный — можно использовать недорогие платные инструменты
- Не ограничен — качество важнее стоимости"

**Вопрос 3:** "Что важнее для вашей аудитории? Оцените от 1 (важнее полнота функциональности) до 5 (важнее простота использования)."

После получения всех трёх ответов — агент скорит гипотезы и продолжает без дополнительных вопросов.

---

## Секция 3: Скоринг гипотез

Каждая гипотеза оценивается по трём критериям от 1 до 5:

| Критерий | Источник |
|----------|----------|
| Скорость реализации | Оценка агента на основе сложности гипотезы |
| Соответствие бюджету | Соответствие ответу пользователя |
| Простота для аудитории | Оценка агента на основе описания гипотезы |

Итоговый балл = взвешенная сумма с весами из ответов пользователя. Гипотеза с наивысшим баллом становится финалистом для верификации.

## Секция 4: Структура отчёта (Google Doc)

**Название документа:** `[Тема исследования] — Гипотезы [ДД.ММ.ГГГГ]`

**Язык:** всегда русский, независимо от языка источников.

```markdown
# Верификация гипотез: [Тема исследования]
Дата: [ДД.ММ.ГГГГ] | Проблема: [из отчёта] | Аудитория: [из отчёта]

## 1. Исходные данные
Краткое резюме отчёта ресёрч-агента: проблема, аудитория, ключевые факты.

## 2. Гипотезы решений
### Гипотеза 1: [Короткое название]
[Описание — что предлагаем, как это решает проблему аудитории]

### Гипотеза 2: [Короткое название]
[Описание]

### Гипотеза N: [Короткое название]
[Описание]

## 3. Критерии оценки
— Скорость реализации: [значение из диалога]
— Бюджет: [значение из диалога]
— Простота для аудитории: [значение из диалога]

## 4. Скоринг гипотез
| Гипотеза | Скорость | Бюджет | Простота | Итого |
|----------|----------|--------|----------|-------|
| Гипотеза 1 | ... | ... | ... | ... |
| Гипотеза 2 | ... | ... | ... | ... |

## 5. Верификация финалиста
Результаты 1-2 целевых поисковых запросов:
— примеры успешных реализаций похожих решений
— известные провалы и их причины
— рыночные данные (размер рынка, конкуренты, спрос)

## 6. Выбранная гипотеза
[Детальное описание победителя]

**Обоснование выбора:** [почему эта гипотеза лучше остальных по критериям]

**Описание решения:** [что именно предлагаем создать, как это работает]

## 7. Необходимые функции
— [Функция 1]: [краткое описание]
— [Функция 2]: [краткое описание]
— [Функция N]: [краткое описание]
```
