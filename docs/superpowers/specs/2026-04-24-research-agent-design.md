# Дизайн: Ресёрч-агент (AI-Секретарь)

**Дата:** 2026-04-24
**Проект:** AI-Секретарь — агентная система личного ассистента
**Приоритет:** Первый агент к реализации

---

## Обзор

Ресёрч-агент — суб-агент системы AI-Секретарь. Принимает тему для исследования, задаёт уточняющие вопросы, проводит параллельный поиск через Brave Search и FireCrawl, синтезирует результаты и сохраняет структурированный отчёт в Google Docs на русском языке.

---

## Секция 1: Архитектура

### Поток работы

```
Запрос пользователя
    → Координатор (CLAUDE.md) распознаёт исследовательский запрос
    → Запускает .claude/agents/research-agent.md как суб-агента
    → Агент задаёт 3 уточняющих вопроса (по одному)
    → Параллельный поиск: Brave Search (10-15 источников) + FireCrawl (краул топ-5 наиболее релевантных)
    → Синтез отчёта на русском языке
    → Создание Google Doc с отчётом
    → Возврат прямой ссылки пользователю
```

### Файловая структура

```
.claude/
  agents/
    research-agent.md    ← файл агента
  settings.json          ← MCP-конфигурация (обновляется)
CLAUDE.md                ← координатор (создаётся)
```

### Необходимые MCP

| MCP | Назначение | API-ключ |
|-----|------------|----------|
| `@modelcontextprotocol/server-brave-search` | Широкий поиск 10-15 источников | `BRAVE_API_KEY` |
| `firecrawl-mcp` | Глубокий краул топ-5 страниц (полный текст) | `FIRECRAWL_API_KEY` |
| `@modelcontextprotocol/server-gdrive` | Создание документов в Google Drive | Google OAuth |

Все API-ключи хранятся в переменных окружения в `settings.json` (секция `env`).

## Секция 2: Уточняющие вопросы

Агент задаёт вопросы по одному, ожидая ответа после каждого:

1. **Проблема:** "Какую проблему хотите решить?"
2. **Аудитория:** "Опишите целевую аудиторию, для которой вы хотите решить проблему."
3. **Глубина:** "Какая глубина нужна?"
   - Обзор — 5 источников
   - Стандарт — 10 источников
   - Глубокий — 15+ источников

После получения ответов на все 3 вопроса агент сразу начинает исследование без дополнительных подтверждений.

## Секция 3: Структура отчёта

Язык отчёта: **всегда русский**, независимо от языка источников.

Название Google Doc: `[Тема] — Исследование [дата]`

```markdown
# [Тема исследования]
Дата: [дата]  |  Глубина: [выбранная]  |  Аудитория: [из вопроса 2]

## 1. Краткий вывод
2-3 абзаца: главный ответ на вопрос "какую проблему решаем"

## 2. Ключевые факты
— [факт 1]
— [факт 2]
...

## 3. Детальный анализ
### [Аспект/тема 1]
### [Аспект/тема 2]
...

## 4. Решения

### Платные сервисы (3 варианта)
| Сервис | Цена | Что решает | Ссылка |
|--------|------|------------|--------|
| ...    | ...  | ...        | ...    |

### Бесплатные сервисы (3 варианта)
| Сервис | Ограничения | Что решает | Ссылка |
|--------|-------------|------------|--------|
| ...    | ...         | ...        | ...    |

## 5. Источники
1. [Название страницы] — [URL]
...
```

## Секция 4: Настройка MCP

### Brave Search MCP
- **Пакет:** `@modelcontextprotocol/server-brave-search`
- **API-ключ:** Бесплатный тариф на brave.com/search/api (2000 запросов/мес)
- **Переменная:** `BRAVE_API_KEY`

### FireCrawl MCP
- **Пакет:** `firecrawl-mcp`
- **API-ключ:** Доступен на firecrawl.dev (есть бесплатный тариф)
- **Переменная:** `FIRECRAWL_API_KEY`

### Google Docs MCP
- **Пакет:** `@modelcontextprotocol/server-gdrive`
- **Авторизация:** Google OAuth (однократная через браузер)
- **Scope:** создание и редактирование документов в Google Drive

Конфигурация в `settings.json`:
```json
{
  "mcpServers": {
    "brave-search": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-brave-search"],
      "env": { "BRAVE_API_KEY": "${BRAVE_API_KEY}" }
    },
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}" }
    },
    "gdrive": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-gdrive"]
    }
  }
}
```

## Секция 5: Координатор (CLAUDE.md)

CLAUDE.md служит инструкцией для главного Claude — описывает всю команду агентов и правила маршрутизации.

### Триггеры для запуска research-agent

- "исследуй / найди информацию / сделай ресёрч / изучи тему"
- "что такое [тема]", "как работает [тема]"
- "найди сервисы / инструменты / решения для..."
- "сделай анализ рынка / конкурентов"
- "собери информацию по..."

### Правила маршрутизации

- Координатор **никогда** не отвечает сам на исследовательские запросы
- Передаёт агенту: оригинальный запрос + контекст разговора
- CLAUDE.md содержит секции для всех 5 агентов (добавляются по мере реализации)
