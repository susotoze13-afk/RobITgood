Мне необходимо создать агентную систему "AI-RobITGood"

Смысл заключается в том, что это будет агентный сервис, кторый будет создавать open-source сервисы для решения проблем любой целевой аудитории . Делает руками всю рутину за продуктовую команду: исследует, анализирует, проверяет гипотезы, создает дизайн и разрабатывает open-source решения.

Есть главная боль - сделать дорогие платные сервисы доступнее для тех, кто не может их себе позволить.

# CONTEXT:

Должна быть команда из 6 агентов

Координатор — главный мозг, читает мои сообщения и решает, кого звать
Ресёрч-агент — ходит в интернет, находит информацию, делает глубокий ресерч по теме.

Агент-верификатор гипотез - на основе результатов исследования формирует гипотезы по наиболее эффективному решению проблем целевой аудитории

Агент-продакт-менеджер в роли владельца продукта формирует  детальное описание пользовательских историй с критериями приемки, функций  сервисов

Агент-прототипер - На основе пользовательских сценариев с критериями приемки готовит кликабельный html/css прототип

Агент-аналитик - на основе  результата работы агента-верификатора гипотез проводит глубокое изучение предложенного решения и на основе этого формирует  2 спецификации:  на разработку дизайна и на разработку бэкенда/фронтенда, базы данных  open-souce аналога, который должен заменить платные сервисы для решения проблем целевой аудитории.

Агент-дизайнер - на основе спецификации для разработки дизайн макетов агент готовит макеты.

Агент-разработчик - на основе спецификаций  и макетов создают архитектуру, базу данных, фронтенд и бэкенд сервиса. если необходимо, то лучше разбить агента-разработчика на агента-архитектора, агента-бэкенд-разработчика, агента-фронтенд-разработчика.

Агент-тестировщик - тестирует результат работы агента-разработчикапишет юнит-тесты, тест-кейсы, проверяет UI и UX, корректность работы сервиса и полноту , качество решения проблемы целевой аудитории.

## Координатор:

CLAUDE.md - Этот файл и будет являться главным координатором нашего проекта, где будет описано все агенты, кто для чего нужен, когда кого в каких случаях запускать, также там должна быть описана обязательная архитектура проекта нашег, правила запуска каждого агента и полная документация по текущему проекту.

## Ресёрч-агент

Задача этого агента будет подключаться к MCP FireCrawl, а также Brave search - для того, чтобы искать информацию в интернете на определенный запрос, который мы будем ему задавать. его задача будет проанализировать детально ту тему, которую мы в него загрузили. Далее найти информацию в интернете по этой теме. собрать из разных источников эту информацию, после этого сформировать отчет пользователю в формате google docs (MCP)

Нам необходимо этих агентов создать в папке .claude/agents, так как мы будем запускать их в режиме субогентов, а также в режиме agent teams.

## Агент-верификатор гипотез

- на основе результатов исследования формирует гипотезы по наиболее эффективному решению проблем целевой аудитории, озвученные пользователем на первом этапе ресерч-агенту, далее проверяет, верифицирует их и отбирает одну самую подходящую  гипотезу, на основе которой можно наиболее эффективно и быстро решить проблему целевой аудитории с минимальными усилиями. В результате, должен появиться документ с детально описанными гипотезами, результатами их верификации, обоснования и с детальным описанием действий, набором функции, которые необходимы для решения проблемы целевой аудитории.

## Агент-продакт-менеджер

- на основе  результата работы агента-верификатора гипотез проводит глубокое изучение предложенного решения и на основе этого формирует  детальное описание пользовательских историй с критериями приемки, функций  сервисов, которые полезны для решения проблемы целевой аудитории, озвученные пользователем на первом этапе ресерч-агенту.
